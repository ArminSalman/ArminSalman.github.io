# Armin Salman — Portfolyo

Türkçe, koyu temalı ve mobil uyumlu kişisel portfolyo. Bağımlılık veya derleme gerektirmez.

## Önizleme

`index.html` dosyasını tarayıcıda açın veya bu dizinde `python -m http.server 8000` çalıştırın.

## GitHub Pages

Dosyaları `ArminSalman.github.io` deposunun `main` dalına yükleyin. Settings → Pages → Deploy from a branch → main / (root) seçin. Yayın adresi: https://arminsalman.github.io/

İçerik `index.html` dosyasından düzenlenebilir. Proje açıklamaları herkese açık GitHub README dosyalarına dayanır. Eğitim, iş deneyimi ve kişisel iletişim bilgileri eklenmemiştir.
